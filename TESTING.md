# Validation — September 26, 2026

Environment: Apple silicon, macOS 26.6.2, Swift 6.3.3. Built using Command Line Tools without full Xcode. Clipboard tests must run with access to the macOS pasteboard service; restricted sandboxes can block even named pasteboards.

## Automated checks

The dependency-free `StashCoreChecks` executable exercises the production core against named, isolated macOS pasteboards and temporary directories.

1. Monitoring ignores clipboard contents that predate startup and reads each new copy once.
2. Copies skipped while paused or excluded do not reappear on resume or app switches.
3. Restoring a clip does not recapture it.
4. Text, URL, email, and hex-color classification, including invalid input.
5. Rich-text/HTML round-trip and plain-text conversion.
6. Concealed, transient, autogenerated, restored, and remote markers block capture.
7. Password-manager and custom app exclusions block capture.
8. Multiple files preserve file URLs and separate pasteboard items.
9. PNG image decoding and video-file classification.
10. Unsupported formats and copies over 20 MB are skipped.
11. Deduplication preserves pin state and identity while updating recency.
12. Retention and count limits preserve pinned clips.
13. Case-insensitive multi-term search, category and pin filtering.
14. Saved history round-trip, owner-only permissions, and corrupt-file errors.
15. Missing history and empty clipboard behavior.

## Boundaries

- Automatic cross-app pasting requires user-granted Accessibility access. Permission was not granted during testing, so injection into another app is not claimed as verified.
- The global Carbon hotkey registers successfully. The UI automation's app-targeted synthetic shortcut did not establish a reliable system-wide hotkey result; manually check ⌘⇧V after opening the release app.
- Core monitoring is verified with real isolated pasteboards. Background collection of the user's actual clipboard is intentionally left off until Start collecting is selected.
- The app was tested on this Apple silicon Mac, not Intel or earlier macOS releases.
- Public Developer ID signing, notarization, and an automatic updater are not included. The local app is ad-hoc signed.

## Shortcut reliability — build 3

## Maintainability refactor

Run `./scripts/check.sh` for the debug app build and all core checks; run
`./scripts/format.sh --check` for Swift formatting. Checks are split by behavior
and registered explicitly in `Tests/StashCoreTests/CoreChecks.swift`.

New regressions cover pin-exempt byte budgets, newest-prefix eviction, compiled
Unicode search, UTF-8 prompt validation, replacing saved files and repairing
permissions, suppressing queued screenshot failures after stop, and releasing an
active screenshot observer. The baseline had 33 checks; the refactor has 40.

Repeat manual keyboard navigation, prompt editing, inline Settings, screenshot
pause/resume, and cross-app paste flows after UI changes. Automated core checks
do not verify those interactions or older macOS compatibility.
