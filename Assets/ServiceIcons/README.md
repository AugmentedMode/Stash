Service icons
=============

GitHub: bundled from https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png on 2026-09-28. Used to identify GitHub links. GitHub marks belong to GitHub.

Figma and Google document marks are compact SwiftUI vector drawings in ClipIcons.swift. Notion uses its official outlined cube mark. All service icons render locally without network requests or installed-app dependencies.

Assets added 2026-09-28:
- Notion: https://www.notion.so/images/favicon.ico (64px frame).
- Claude: https://claude.ai/favicon.ico (48px frame).
- Perplexity: https://www.perplexity.ai/favicon.ico (48px frame).
- Gemini: https://www.gstatic.com/lamda/images/gemini_sparkle_4g_512_lt_f94943af3be039176192d.png (linked from gemini.google.com).
- ChatGPT: icon-chatgpt.icns from the locally installed OpenAI app, converted to PNG.

Marks identify their respective services and belong to their respective owners. Icons are bundled; clipboard content is never sent to these services to resolve an icon.

Expanded service set (2026-09-28): Slack, Linear, Jira, Google Drive, Dropbox, OneDrive, YouTube, Loom, Zoom, Google Meet, Microsoft Teams, Cursor, Copilot, and Grok. Public site favicons were downloaded through `https://www.google.com/s2/favicons?domain=DOMAIN&sz=128`, using slack.com, linear.app, jira.com, drive.google.com, dropbox.com, onedrive.live.com, youtube.com, loom.com, zoom.us, meet.google.com, teams.microsoft.com, cursor.com, copilot.microsoft.com, and grok.com respectively. Linear and Copilot ICO responses were converted to PNG. Codex uses app.icns from the locally installed OpenAI app (bundle ID com.openai.codex), converted to PNG.

Recognition is offline. Jira recognition on atlassian.net is limited to /browse and /jira paths; Confluence pages are not labeled Jira. Codex recognition on chatgpt.com is limited to /codex. Native AI source marks use exact bundle IDs. Text styles only recognize valid JSON objects/arrays, tagged fenced code, and explicit shell prompts or supported shebangs; they never execute content or change its clipboard type.
